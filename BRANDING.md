# JARVIS Desktop AI — Branding Notes

## Project identity

**Display name:** JARVIS Desktop AI  
**Short description:** A customizable desktop voice assistant with a compact floating HUD.

## UI language

- Use “JARVIS Desktop AI” in the launcher and project documentation.
- Use “Mini Assistant” or “Mini Mode” for the compact companion window.
- Use “OPEN HUD” for the action that restores the main interface.
- Avoid implying affiliation with a company, movie franchise, or upstream maintainer beyond the actual project relationship.

## Notes

This branding update changes display text only; it does not change the assistant's API providers or core identity/configuration values.
