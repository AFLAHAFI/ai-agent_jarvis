# Proposed Changes

## Mini Assistant HUD

- Added a compact, frameless, draggable, always-on-top Mini Assistant window.
- Added a **▣ MINI** button to the main HUD.
- Added **Ctrl+M** as a shortcut to enter Mini Mode.
- Added **OPEN HUD** controls to restore the main interface.
- Preserves the main window's previous geometry when switching back.
- Refreshed the window title and HUD subtitle branding.
- Added README and branding notes.

- Full GUI runtime behavior and compatibility with the latest upstream changes still require testing on a desktop.
